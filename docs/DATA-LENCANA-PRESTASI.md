## 📌 Ringkasan Sistem
Sistem Lencana Prestasi ini terdiri dari **20 Kategori Tematik**, di mana setiap kategori memiliki evolusi **4 Tingkatan Prestise (Tier)**:
- 🥉 **COMMON**: Tingkat dasar / pemula (Warna: Emas Tembaga / `#f59e0b`)
- 🥈 **RARE**: Tingkat menengah / terampil (Warna: Biru Safir Azure / `#38bdf8`)
- 🥇 **EPIC**: Tingkat tinggi / mahir (Warna: Emas Kerajaan & Ruby / `#fbbf24`)
- 💎 **LEGEND**: Tingkat legendaris / puncak kejayaan (Warna: Obsidian & Kosmik Ungu / `#c084fc`)

**Total Keseluruhan:** $20 \times 4 = \mathbf{80\text{ Lencana Unik}}$.

## 🛠️ Integrasi Teknis & Kode Sumber

- **Definisi Logika**: [`shared/badges.js`](file:///home/maman/play/shared/badges.js)
  - Modul universal (Node.js & Browser ES) berisi seluruh metadata, konstanta warna tier, target numerik, dan fungsi `evaluateBadges(stats)`.
- **Database & Evaluasi**: [`lib/db.js`](file:///home/maman/play/lib/db.js)
  - `getPlayerProfile(playerId)`: Mengumpulkan seluruh metrik statistik in-game dan mengevaluasi status lencana pemain secara dinamis.
  - `updatePlayerShowcase(playerId, showcaseArray)`: Menyimpan 3 slot lencana/gelar pilihan pemain ke kolom `showcase_json` di tabel `players`.
  - `getPlayerPublicProfile(targetPlayerId)`: Menyediakan data publik lengkap bagi pemain lain saat melihat profil teman di arena pertemanan.
- **REST API Endpoints**: [`server.js`](file:///home/maman/play/server.js)
  - `GET /api/profile`: Mengembalikan profil akun, statistik lengkap, 3 showcase, dan seluruh lencana terbuka.
  - `POST /api/profile/showcase`: Memperbarui 3 lencana/gelar di Panggung Kehormatan.
  - `GET /api/friends/:id/profile`: Mengembalikan detail profil teman, total lencana terbuka, showcase, total skin, dan statistik lengkap.
- **Frontend Interaktif**: [`public/js/app.js`](file:///home/maman/play/public/js/app.js) & [`public/js/friends.js`](file:///home/maman/play/public/js/friends.js)
  - Panggung Kehormatan 3 Slot interaktif di Profil.
  - Pemisahan statistik Bintang dan Rekor Kombo ke dalam grid 10 kotak metrik.
  - Pop-up modal rincian 4 tier lencana dengan tombol langsung *"Pasang di Showcase"*.
  - Modal profil detail teman di halaman pertemanan lengkap dengan tombol Tantang Duel.
