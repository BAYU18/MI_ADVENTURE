## 1. Ikhtisar Pet Hadiah Lencana

Di dalam game *Petualangan Pelajar*, **Pet (Peliharaan / Hewan Pendamping)** menempati slot khusus avatar di sisi kiri bawah karakter petualang. Selain memperindah visual karakter dengan animasi aura dinamis, setiap pet dibekali **Efek Pasif RPG** yang aktif secara otomatis saat bertarung melawan Monster Bos maupun saat beradu kecerdasan di Arena Duel PvP.

Sebagian besar pet biasa dapat diperoleh dari toko atau gacha peti harta karun mode cerita. Namun, terdapat **Pet Eksklusif Tingkat Tertinggi (Tier LEGEND)** yang tidak dapat dibeli dengan koin maupun koin top-up mana pun; pet ini **hanya dapat diperoleh sebagai ganjaran kehormatan tertinggi dari penyelesaian Lencana Legendaris (Badge Tier Legend)**:

## 5. Spesifikasi Teknis Kode SVG & Efek Partikel Visual

Pada arsitektur visual avatar game (`shared/avatar.js` & `public/js/avatar.js`), pet dirender pada koordinat `(cx: 32, cy: 160)` di sisi kiri bawah karakter dengan lapisan bertingkat:

### A. Struktur Visual Layer Pet
1. **Bayangan Tanah (Ground Shadow)**:
   - `<ellipse cx="32" cy="182" rx="28" ry="6.5" fill="url(#pp-{uid})"/>`
   - Memberikan kesan melayang (*hovering floating effect*).
2. **Aura Pulsasi Berdenyut (Pulsing Glow Aura)**:
   - Menggunakan animasi `@keyframes auraPulse` / `.fx-pulse` dengan radius `r="34"`.
   - Warna gradien emas untuk Naga (`#f59e0b` ke `#fbbf24`), dan crimson-fire untuk Phoenix (`#ef4444` ke `#f97316`).
3. **Taburan Partikel Bintang & Bara (Twinkle Stars & Rising Embers)**:
   - Naga Langit: Menggunakan elemen path bintang 4 sudut berkedip (`.fx-twinkle`).
   - Burung Phoenix: Menggunakan partikel bara api melayang ke atas (`.fx-rise` / `@keyframes emberFloat`).
4. **Sprite Aset Utama**:
   - Memanfaatkan vektor Twemoji SVG resolusi tinggi dengan filter drop shadow 3D:
     `filter: drop-shadow(0 4px 10px rgba(245,158,11,0.6))`

### B. Cuplikan Kode Render SVG (Implementasi Avatar Engine)
```javascript
// Render Elemen Pet Avatar (shared/avatar.js)
renderPetElement(petId, uid) {
  if (!petId || !PET[petId]) return '';
  const code = PET[petId];
  const isLegend = (petId === 'pet_dragon' || petId === 'pet_phoenix');
  const isEpic = (petId === 'pet_owl');
  const isRare = (petId === 'pet_penguin' || petId === 'pet_fox');

  // 1. Bayangan & Aura Dasar
  let petAura = `<ellipse cx="32" cy="182" rx="28" ry="6.5" fill="url(#pp-${uid})"/>`;
  let petExtra = '';

  // 2. Efek Partikel Khusus Tier Legenda
  if (isLegend) {
    if (petId === 'pet_dragon') {
      // Aura Emas Kosmik & Partikel Bintang Berkedip
      petAura += `<circle class="fx-pulse" cx="32" cy="160" r="34" fill="url(#pg-${uid})"/>`;
      petExtra += `
        <g transform="translate(10 140) scale(0.8)">
          <path class="fx-twinkle" style="animation-delay:0.3s" fill="#fff" d="M0 -7Q1 -1 7 0Q1 1 0 7Q-1 1 -7 0Q-1 -1 0 -7Z"/>
        </g>
        <g transform="translate(56 150) scale(0.7)">
          <path class="fx-twinkle" style="animation-delay:0.9s" fill="#fef08a" d="M0 -7Q1 -1 7 0Q1 1 0 7Q-1 1 -7 0Q-1 -1 0 -7Z"/>
        </g>
      `;
    } else if (petId === 'pet_phoenix') {
      // Aura Kobaran Api Merah Menyala & Percikan Bara Melayang
      petAura += `<circle class="fx-pulse" cx="32" cy="160" r="34" fill="url(#pfire-${uid})"/>`;
      petExtra += `
        <circle class="fx-rise" style="animation-delay:0.0s" cx="28" cy="155" r="2.2" fill="#f97316"/>
        <circle class="fx-rise" style="animation-delay:0.7s" cx="38" cy="162" r="1.8" fill="#facc15"/>
        <circle class="fx-rise" style="animation-delay:1.4s" cx="22" cy="168" r="1.5" fill="#ef4444"/>
      `;
    }
  }

  // 3. Gabungkan Layer Menjadi 1 Kesatuan Komponen
  return `
    <g class="pet-slot-container" data-pet="${petId}">
      ${petAura}
      <g transform="translate(8, 136)">
        <image href="${TWEMOJI_URL}/${code}.svg" width="48" height="48" style="filter:drop-shadow(0 6px 12px rgba(0,0,0,0.5))" />
      </g>
      ${petExtra}
    </g>
  `;
}
```

## 6. Panduan Membuka & Mengklaim Pet Lencana

Bagi para pemain yang ingin mendapatkan pet hadiah lencana ini, berikut alur perjalanannya:

1. **Pantau Kemajuan Lencana di Menu Showcase / Profil**:
   - Buka menu **Profil Petualang** atau tab **Lencana Kehormatan**.
   - Periksa kartu lencana **Penjelajah Kampanye** (untuk Anak Naga Langit) atau **Penyintas Hati Phoenix** (untuk Bayi Burung Phoenix).
2. **Capai Target Syarat Prestasi**:
   - *Anak Naga Langit*: Selesaikan stage node Mode Cerita hingga mencapai minimal 25 stage.
   - *Bayi Burung Phoenix*: Mainkan pertempuran bos/duel dan raih kemenangan dalam kondisi HP kritis (â‰¤ 20%) sebanyak 25 kali.
3. **Klaim Hadiah Lencana**:
   - Begitu target tercapai, lencana akan menyala emas berkilau dan menampilkan notifikasi klaim hadiah.
   - Ketuk tombol **Klaim Hadiah ðŸŽ**; koin emas, XP, dan Pet Eksklusif otomatis masuk ke dalam inventaris akun.
4. **Pasang Pet di Lemari Avatar**:
   - Masuk ke menu **Kustomisasi Avatar** âž” pilih tab **Peliharaan (Pet)**.
   - Ketuk ikon pet legendaris yang telah dibuka, lalu klik **Pasang di Karakter**.
